# LabelSpy — открытый шаблон Telegram-бота для AI-анализа состава продуктов и спортивного питания

Готовый к развёртыванию шаблон Telegram-бота, который распознаёт этикетки по фотографии, анализирует ингредиенты с помощью Google Gemini Vision AI, находит вредные добавки и формирует визуальные карточки-отчёты.

---

## Возможности бота

- 🔍 **AI-анализ состава по фото:** распознавание этикеток продуктов, добавок и спортивного питания через мультимодальный Google Gemini Vision.
- 🎯 **Оценка безопасности 1–10:** автоматический расчёт честного рейтинга качества и чистоты сырья.
- ⚠️ **Красные флаги и плюсы:** моментальное выявление скрытого сахара, трансжиров, опасных красителей, Е-кодов и положительных ингредиентов.
- 🖼 **Графическая карточка-отчёт (PNG):** генерация стильной инфографики 900x520 со шкалой оценки и вердиктом эксперта для сохранения или пересылки.
- 📅 **Ежемесячный лимит сканов:** бесплатный настраиваемый пул проверок на календарный месяц (с фиксацией границы по UTC).
- ⭐ **Монетизация через Telegram Stars:** встроенный приём платежей за ежемесячную подписку в цифровой валюте Stars (XTR) с идемпотентным учётом платежей.
- 👤 **Профиль пользователя:** отображение статуса подписки, оставшихся бесплатных попыток и даты окончания доступа.
- 🛡 **Защита от спама и злоупотреблений:** атомарная блокировка параллельных запросов и настраиваемый кулдаун между сканированиями.
- ⚙️ **Два режима работы базы данных:** автоматическое использование встроенной SQLite для простого запуска либо PostgreSQL для высоконагруженного облачного деплоя.
- 🎨 **Гибкое оформление:** поддержка как кастомных Telegram Premium эмодзи, так и универсальных стандартных Unicode-эмодзи.

---

## Стек технологий

- **Язык:** Python 3.11+
- **Telegram Framework:** `python-telegram-bot` 22.7 (асинхронный polling)
- **Искусственный интеллект:** Google Gemini Vision (`google-generativeai` через стабильный REST-транспорт)
- **Графика и карточки:** `Pillow` (PIL) с поддержкой кириллических TTF-шрифтов (Roboto / DejaVu)
- **База данных:** SQLite (по умолчанию) / PostgreSQL (`psycopg2-binary` с пулом соединений `ThreadedConnectionPool`)
- **HTTP / Сеть:** `httpx`, встроенный health-сервер на стандартной библиотеке Python

## Запуск под себя

Развернуть собственного бота на базе этого шаблона можно за 5 шагов:

### Шаг 1. Создание Telegram-бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте команду `/newbot`.
2. Задайте отображаемое имя и уникальный username бота.
3. Скопируйте полученный **HTTP API Token** (вида `123456789:ABCdef...`).

### Шаг 2. Получение ключа Google Gemini API
1. Перейдите в [Google AI Studio](https://aistudio.google.com/).
2. Войдите в аккаунт Google и нажмите **«Get API key»** -> **«Create API key»**.
3. Скопируйте созданный ключ.

### Шаг 3. Настройка файла окружения
Склонируйте репозиторий и создайте файл `.env` на основе примера:
```bash
git clone <url-вашего-репозитория>
cd LabelSpy
cp .env.example .env
```
Откройте файл `.env` в любом текстовом редакторе и укажите полученные ключи:
```dotenv
TELEGRAM_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
BOT_NAME=ВашеИмяБота
BOT_USERNAME=ваш_юзернейм_бота_без_собачки
```

### Шаг 4. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv

# Активация на Windows:
venv\Scripts\activate

# Активация на Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### Шаг 5. Запуск бота
```bash
python bot.py
```
Бот автоматически инициализирует базу данных, запустит фоновый health-сервер и начнёт принимать сообщения.

## Таблица параметров конфигурации (`.env`)

Все параметры настраиваются через переменные окружения без необходимости вносить правки в исходный код:

| Переменная | Обязательно | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `TELEGRAM_TOKEN` | **Да** | — | Токен вашего бота от `@BotFather` |
| `GEMINI_API_KEY` | **Да** | — | API-ключ Gemini от Google AI Studio |
| `DATABASE_URL` | Нет | — | URL подключения к PostgreSQL (`postgresql://...`). Если пусто, используется SQLite (`labelspy.db`) |
| `ADMIN_ID` | Нет | — | Числовой Telegram ID администратора. Если не задан, админ-функции (`/stats`, тестовый доступ) отключены |
| `BOT_NAME` | Нет | `LabelSpy` | Отображаемое название бота в текстах и шапке отчёта |
| `BOT_USERNAME` | Нет | *пусто* | Юзернейм бота в Telegram (без `@`) для подписи на карточке-отчёте |
| `GEMINI_MODELS` | Нет | `gemini-2.5-flash,gemini-2.0-flash,gemini-1.5-flash,gemini-1.5-pro` | Список моделей Gemini с поддержкой Vision (через запятую) в порядке приоритета |
| `HTTPS_PROXY` / `HTTP_PROXY` | Нет | — | Прокси для локального запуска в регионах с ограничениями Google Gemini (например, РФ) |
| `FREE_SCANS_PER_MONTH` | Нет | `5` | Количество бесплатных сканирований в календарный месяц |
| `PREMIUM_STARS_PRICE` | Нет | `50` | Стоимость подписки в Telegram Stars (XTR) |
| `PREMIUM_SUBSCRIPTION_DAYS` | Нет | `30` | Длительность платной подписки в днях |
| `DEMO_PREMIUM_DAYS` | Нет | `7` | Длительность тестового премиума для администратора |
| `SCAN_COOLDOWN_SECONDS` | Нет | `3` | Минимальная пауза между запросами пользователя (секунды) |
| `USE_CUSTOM_EMOJI` | Нет | `false` | Включить кастомные эмодзи Telegram Premium (`true`/`false`). Если `false`, используются стандартные Unicode-эмодзи |

## Кастомизация бота (config.py)

### Изменение названия и юзернейма
Вы можете задать имя через переменные в `.env` либо изменить значения по умолчанию в `config.py`:
```dotenv
BOT_NAME=CleanBite
BOT_USERNAME=CleanBiteBot
```
Имя обновится во всех сообщениях, меню, заголовках и инфографиках.

### Изменение цен и лимитов
Настроить тарифы и лимиты под свой проект можно в `.env` или отредактировав константы в `config.py`:
```dotenv
FREE_SCANS_PER_MONTH=10
PREMIUM_STARS_PRICE=100
PREMIUM_SUBSCRIPTION_DAYS=30
```

### Настройка эмодзи
В проекте предусмотрен модуль `emoji_helper.py`. Если ваш бот не имеет прав на кастомные паки эмодзи Telegram Premium, оставьте в `.env`:
```dotenv
USE_CUSTOM_EMOJI=false
```
Бот будет использовать аккуратные стандартные Unicode-эмодзи (🤖, 📊, 🔍, ✅, ❌, ⭐).

## Подключение PostgreSQL

По умолчанию бот работает на локальной базе данных SQLite (`labelspy.db`), которая не требует настройки.

Для работы в облаке или с несколькими процессами достаточно указать строку подключения к любой облачной PostgreSQL (Supabase, Neon, Render Postgres, Railway):
```dotenv
DATABASE_URL=postgresql://user:password@host:5432/dbname
```
При запуске бот автоматически:
- Определит тип базы данных;
- Применит все миграции схемы (таблицы `users`, `scans`, `payments`);
- Включит пул постоянных соединений `ThreadedConnectionPool` для минимизации задержек сетевых запросов.

## Развёртывание в облаке (Deploy)

Проект полностью готов для деплоя на платформы **Render**, **Railway**, **Koyeb**, **Heroku** или собственный **VPS**:

- В корне проекта уже есть `Procfile`:
  ```text
  web: python bot.py
  ```
- В `bot.py` встроен легковесный HTTP health-сервер на порту `$PORT` (по умолчанию `10000`), отвечающий `200 OK` на GET-запросы по пути `/`. Это позволяет облачным платформам корректно отслеживать статус сервиса и не перезагружать контейнер.
- Для предотвращения «засыпания» бесплатного контейнера на Render достаточно добавить бесплатный пинг адреса вашего приложения через UptimeRobot раз в 10 минут.

## Тестирование

Все тесты работают строго локально без сетевых обращений к Telegram или Gemini:
```bash
python test_suite.py
```
Набор тестов проверяет:
- Автоматические миграции и обратную совместимость схемы БД;

- Месячный лимит бесплатных сканирований;
- Защиту от конкурентных запросов;
- Валидацию и нормализацию JSON-ответов нейросети;

- Генерацию графической карточки с кириллицей и работу кэша шрифтов.

## Важно

1. **Собственные ключи:** бот не заработает без указания ваших собственных `TELEGRAM_TOKEN` и `GEMINI_API_KEY` в файле `.env`.
2. **Безопасность:** никогда не коммитьте файл `.env` в git-репозиторий и не публикуйте секретные токены.
3. **Платежи Telegram Stars:** для работы платежей бот должен быть настроен в `@BotFather` (раздел *Payments*, для Stars провайдер не требуется).
4. **Отказ от ответственности:** AI-анализ этикеток носит исключительно ознакомительный и справочный характер и не является медицинским или фармацевтическим заключением.
